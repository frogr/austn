This was one of the first things I ever built with Claude Code, back when it was in beta and billed by API usage.

It's a website for planning a Minecraft build in 3D before you build it in the game: place and remove blocks, pick materials, move the camera around. I'd never used Three.js before. We had it working in about an hour.

It's here mostly for nostalgia.
